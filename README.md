# The Manufacturer MX Awards 2026: Round 2 Presentation

Round 2 presentation for the **Technology Champion** category, by **Vaikunth Guruswamy**,
Software Application Engineer at **ZOT Engineering Ltd**.

It tells the story of digitalising a three-division contract electronics manufacturer
(PCB manufacturing, assembly and sheet metal fabrication) from the inside: the starting
point, how the work was delivered, the platform as it runs today, and the results.

## Viewing

Open **[`index.html`](index.html)** in any modern browser, or view the hosted version via
GitHub Pages. Scroll, or use the **arrow keys** / **Page Up–Down** to move between sections;
**Home** and **End** jump to the start and finish. The chapter rail on the right lets you
skip to any section.

## Structure

```
index.html          The presentation (generated: do not edit by hand)
build.py            Assembles index.html from the pieces in src/
src/
  head.html         Shared shell: document head, styles, header, chapter rail
  foot.html         Closing wrapper and the navigation script
  sections/         One file per slide, ordered by the leading number
assets/             Brand mark
demos/              Vortex customer-portal demonstration builds
```

## Editing

Each slide lives in its own file under `src/sections/` (for example
`08-architecture.html`). Edit the section you want, then rebuild:

```
python build.py
```

Sections are ordered by their filename, so the leading number (`00-`, `01-`, ...)
controls the running order; rename or renumber a file to move a slide. Shared
elements (styles, the header, the chapter rail, the keyboard and scroll logic)
live in `src/head.html` and `src/foot.html`.

`index.html` is regenerated by `build.py`; edit the files in `src/` rather than
`index.html` directly, or your changes will be overwritten on the next build.

The result is static HTML, CSS and vanilla JavaScript, with no framework and no
external dependencies beyond the web fonts.
